# エスカレーター第1回 フェーズ2計画（シーン制作・並行分割）

前提: フェーズ1の PR が main にマージされ、Muse が test_loop_5s.mp4 の動きを QC 済みであること。
実測の物差し: 960×540・Eevee 16サンプルで 15.16秒/フレーム（120フレーム30分21秒）。1080p は画素4倍で概ね 45〜60秒/フレーム想定。
ループの周期: 6ピッチで配置が元に戻る設計（0.5m/s・ピッチ400mm → 周期 4.8秒）。A1 は周期分だけ描けば編集でタイル状に繰り返せる。

## 描くシーン（設計シート A1〜A8 の残り）
| シーン | 内容 | 長さ | 解像度 | 追加構築の要否 |
|---|---|---|---|---|
| A1 本番 | 全体ループ（看板映像） | 周期 4.8秒＋余裕で約6秒 | 1080p | なし（カメラと設定のみ） |
| A8 透視 | 外装透過で内部ループ | A1と同尺 | 1080p | なし（材質切替） |
| A2 単体 | 黒背景でステップ単体が回転 | 4秒 | 1080p | なし |
| A3 軌道 | 2本のレールと車輪の寄り | 5秒 | 1080p | なし（カメラ） |
| A5 駆動 | モーター→スプロケット→チェーン | 5秒 | 1080p | 駆動部の回転アニメ付け |
| A6 手すり | 速度差 +2% の誇張比較 | 5秒 | 1080p | 比較用の見せ方を新規構築 |
| A4 反事実 | 従動側レールをずらすと段が傾く | 5秒 | 1080p | レール変位バリエーションを新規構築 |
| A7 櫛板 | 溝と櫛歯の噛み合い、異物で浮く | 4秒 | 1080p | 櫛板まわりの寄り＋浮き動作を新規構築 |

合計ユニークフレーム数: 約900フレーム。1080p・約50秒/フレーム換算で総量 約12.5時間 → 4並行で 1タスクあたり 約3時間弱が上限見立て。

## 並行分割（ファイル競合を避けるため担当を分離）
- タスクA（描画中心・Sol 軽〜中）: A1本番＋A8 → production/renders/a1_1080.mp4, a8_xray.mp4
- タスクB（描画中心・Sol 軽〜中）: A2＋A3 → a2_step_solo.mp4, a3_tracks.mp4
- タスクC（構築あり・Sol 高）: A5＋A6 → a5_drive.mp4, a6_handrail.mp4
- タスクD（構築あり・Sol 高）: A4＋A7 → a4_tilt.mp4, a7_comb.mp4
各タスク共通: 冒頭で main へ切り替え（PR マージ後は参照PDFもリポジトリ内にあり fetch 不要になる見込み）。成果物は production/renders/ にファイル名を分けてコミットし、REPORT 追記（実測時間・推測箇所）を残す。

## フェーズ1 QC からの持ち越し判断
- 約2mmの踏面／ライザー重なり: 動画 QC で見え方を確認してから、直すか許容するか決める
- 速度 0.4896 m/s: 問題なし（表示・ナレーションは公称値で語る）

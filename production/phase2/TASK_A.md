# タスクA（描画中心）: A1 本番ループ ＋ A8 透視

共通仕様は `production/phase2/COMMON.md`。担当は次の2シーンのみ。

## A1 本番ループ → `production/renders/a1_hero_1080.mp4`
- フェーズ1の test_loop_5s.mp4 と同じ全体側面カメラで、1920×1080 版を描く
- 長さ 5秒（120フレーム）、継ぎ目なくループすること
- 欄干は共通仕様の修正を適用（手前側パネルを消し、ステップが見える状態）

## A8 透視ビュー → `production/renders/a8_xray_1080.mp4`
- 同じカメラ・同じ尺で、外装と欄干をさらに透かし、トラスも薄くして、内部のステップ循環とチェーンの動きが主役になる画にする
- 駆動部（橙）とチェーンは透かさず残す

## レポート
`production/phase2/REPORT_A.md` に実測時間（フレーム単価・合計）、解像度を落とした場合はその旨、その他の逸脱を書く。完了後ブランチ `phase2-a` を push し PR を作る（マージしない）。

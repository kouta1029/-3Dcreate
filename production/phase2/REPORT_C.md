# エスカレーター機構 Phase 2 タスクC 制作・QC レポート

Phase 1 の `production/escalator_phase1.blend`（main `fde6669`）を土台に、Blender 4.3.2・Eevee 16サンプルで A5 と A6 を制作した。映像は黒背景、無文字、24 fps、各120フレーム（5.000 秒）。手前の欄干パネルを非表示にし、手摺りベルトを残した。奥の欄干パネルの不透明度は 7.5% に下げ、トラスの透過設定は Phase 1 と同じ値にした。

## A5 駆動部

- Phase 1 の上部駆動カメラを使い、乗降板と床スラブを非表示にして、モーターと減速機のケースを半透明にした。モーター入力ロータと減速機出力の回転を、ケース越しに見える模式部品として追加した。
- JP6585230B1 図1・段落0011〜0012の伝達経路に合わせ、橙色の発光がモーター、減速機と出力スプロケット、駆動チェーン、主駆動スプロケット、踏段チェーンの順に強くなる。`TASK_C.md` の列挙に対し、参照資料に従って駆動チェーンを主駆動スプロケットの手前に置いた。
- Phase 1 の駆動チェーン形状から周回中心線を取得し、プレートとピンで組んだ42リンクを等間隔に配置した。出力12歯と主軸側20歯は5秒でそれぞれ24歯分回り、駆動チェーンも同方向へ24リンク分進む。主軸上の踏段側30歯、踏段列、踏段チェーンは Phase 1 の5秒周期を用いた。発光も同じ周期で繰り返す。
- 推測箇所は、42リンクの割り付け、モーター入力ロータと減速機出力の外形・色、入力13回転・出力2回転という演出用の回転数。設計上の歯車列、減速比、ロータ速度、チェーン張力、スプロケットとの噛み合い公差は再現していない。

## A6 手摺り同期

- 固定の正投影カメラで上部乗降口、手摺りベルト、踏段を一緒に映した。同じ水色の目印を踏段と手摺りベルトに付け、初期位置の水平座標をそろえた。踏段の目印は Phase 1 の踏段に固定し、ベルトの目印とゴム表面の反射模様は既存ベルト形状の弧長に沿って同じ速度で進めた。
- **速度差は +10%（踏段の1.10倍）に誇張した。** 仕様書に示された規格差の上限 +2% に対して、速度差を5倍にした図解。Phase 1 の踏段チェーン速度 0.4896 m/s に対し、手摺りベルトの設定速度は 0.53856 m/s。5秒分の経路長の差は 0.2448 m で、画面上の水平方向の差には緩和区間の形状も反映される。A6 は差が開く過程を一方向に示すカット。
- JP6585230B1 図1・段落0013〜0015に基づく Phase 1 の無端経路を使用した。目印の寸法・色、反射模様、初期位置は説明用。摩擦、経年伸び、滑り、実機ごとの速度制御は再現していない。

## レンダー・QC

Phase 1 の全体ループの既存実測は、960×540、Eevee 16サンプルで 15.16 秒/フレーム、120フレームで30分21.01秒だった。[Phase 1 レポート](../REPORT.md#テストレンダー実測)を参照。この環境でも低解像度の出力で Eevee を確認した。Cycles はデノイザーを無効にした CPU テストで動作を確認した。A5・A6 の本番には Eevee を使用した。

A5 の 1920×1080 試し描きは初回 84.28 秒、ウォームアップ後 73.52 秒/フレーム。120フレームの見込みが約2時間27分だったため、共通仕様に従って 1280×720 へ変更した。

A6 の 1920×1080 試し描きは初回 66.20 秒、ウォームアップ後 62.93 秒/フレーム。120フレームの見込みが約2時間6分だったため、同じ規則で 1280×720 へ変更した。

| A5 | 1280×720 | 42.12 | 41.71 | 38.44–72.99 | 84分14.73秒 （5054.73秒） | 6.66 |
| A6 | 1280×720 | 38.40 | 38.09 | 33.42–50.22 | 76分48.39秒 （4608.39秒） | 7.44 |

フレーム単価は Eevee の描画呼び出しから PNG 保存までを実測。連番合計は全120フレームを通した経過時間で、試し描きとエンコードは別計測。FFmpeg で H.264（yuv420p）に変換し、FFprobe で両方の解像度・24 fps・120フレーム・5.000秒を確認した。全フレームのデコードと代表 PNG の読込も確認した。

- A5 はフレーム1と121で、踏段、踏段チェーン、駆動チェーンを同形部品の入れ替えで照合し、配置と姿勢の一致を確認した。ロータの位相も一致した。PNG 上のフレーム120→1の変化量は前後の通常フレームと同程度だった。
- A6 は目印の画面内 X 座標がフレーム1で一致し、フレーム120では手摺り側が画面幅の約5.1%先行した。両方の目印が前景に隠れず読めることを冒頭、中盤、終盤で確認した。

リポジトリのルートから Phase 1 を読み込み、各ショットを再生成・レンダーできる。

```bash
for shot in a5 a6; do
  blender -b production/escalator_phase1.blend --python-exit-code 1 \
    --python production/phase2/build_task_c.py -- "$shot"
  blender -b "production/escalator_${shot}.blend" -t 2 --python-exit-code 1 \
    --python production/phase2/render_task_c.py -- "/tmp/task-c/$shot" --height 720
done
```

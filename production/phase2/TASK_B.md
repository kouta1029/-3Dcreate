# タスクB（描画中心）: A2 ステップ単体 ＋ A3 軌道クローズ

共通仕様は `production/phase2/COMMON.md`。担当は次の2シーンのみ。

## A2 ステップ単体 → `production/renders/a2_step_solo.mp4`
- 黒背景にステップ単体（踏面の溝、黄線、ライザー、前輪・後輪、チェーンリンク付き）を大きく置き、ゆっくり1回転させる
- 長さ 4秒（96フレーム）。回転は継ぎ目なくループできる形（360°で閉じる）

## A3 軌道クローズ → `production/renders/a3_tracks.mp4`
- 傾斜部から上部乗降口への移行区間に寄ったカメラで、2本の案内レール（前輪用・後輪用）と車輪の関係を見せる
- レール2本を発光で強調する。ステップが水平を保ちながら平坦化していく動きが分かること
- 長さ 5秒（120フレーム）、ループ可能に

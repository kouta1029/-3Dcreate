# タスクD（構築あり）: A4 反事実 ＋ A7 櫛板

共通仕様は `production/phase2/COMMON.md`。担当は次の2シーンのみ。どちらもバリエーション構築を含む。

## A4 反事実 → `production/renders/a4_tilt.mp4`
- 「従動側（後輪）のレールを少しずらしたらどうなるか」の実験シーン
- 前半は通常の軌道でステップが水平に進む。後半で後輪側レールの位置がずれ、ステップが目に見えて傾く（傾きは誇張してよい。倍率はレポートに明記）
- 画角は傾斜部の中ほどに寄った側面。ずらすレールは発光で示す
- 長さ 5秒（120フレーム）。ループは不要（前半=正常、後半=異常の対比が内容のため）

## A7 櫛板 → `production/renders/a7_comb.mp4`
- 下部または上部乗降口の櫛板（コムプレート）に寄ったクローズ
- ステップの溝と櫛歯が噛み合いながらステップが消えていく動きを見せる。後半で小さな異物が櫛歯に触れ、櫛板がわずかに浮き上がる動きを入れる（安全スイッチの作動イメージ）
- 櫛板は発光で強調してよい
- 長さ 4秒（96フレーム）

`production/phase2/REPORT_D.md` に実測時間、構築方式、推測・逸脱（A4 の誇張倍率を含む）を書く。完了後ブランチ `phase2-d` を push し PR を作る（マージしない）。

# タスクC（構築あり）: A5 駆動アニメ ＋ A6 手すり同期

共通仕様は `production/phase2/COMMON.md`。担当は次の2シーンのみ。どちらもフェーズ1のモデルにアニメーションを足す作業を含む。

## A5 駆動部 → `production/renders/a5_drive.mp4`
- 駆動部の断面クローズ（フェーズ1の drive_unit.png の画角を土台に）で、モーター→減速機→主スプロケット→駆動チェーン→踏段チェーンの順に動力が伝わる動きを見せる
- 回転部品は実際に回し、チェーンは循環させる。動力の流れが分かるよう、駆動部（橙）を発光で強調してよい
- 長さ 5秒（120フレーム）、ループ可能に

## A6 手すり同期 → `production/renders/a6_handrail.mp4`
- 手すりベルトとステップの速度関係を見せるシーン。手すり上の目印点とステップ上の目印点が、進むにつれて少しずつずれる様子を描く
- 実際の規格差は 0〜+2% で見えないため、**ずれは誇張してよい（目安 +10%）**。ただしレポートに「誇張であること」と倍率を明記する
- 画角は上部乗降口付近の寄り（手すりとステップが同時に見える位置）
- 長さ 5秒（120フレーム）

## レポート
`production/phase2/REPORT_C.md` に実測時間、構築したアニメーションの方式、推測・逸脱（A6 の誇張倍率を含む）を書く。完了後ブランチ `phase2-c` を push し PR を作る（マージしない）。

# D01 フェーズB 修正レポート

PR #7の `.blend` を起点に、対象のコレクションとシーンを更新した。

## V4 平滑ホイル

- ライブラリの `M4_smooth_foil_food` を、M2と同じサツマイモの包みに作り直した。外殻と左右の折り込みはM2と頂点座標が一致し、細長い紡錘形と閉じた両端が残る。外殻の法線を平滑化し、銀色の反射が連続する面に、重ねたホイルの折り返しを一筋入れた。
- V4の2カットは、同一のカメラと照明・背景コレクションを使用。M4の画面高は評価済みメッシュの投影で **85.8%**。V4の配置では、画角に合わせてM4のインスタンスを1.16倍にした。
- 推測箇所は平滑ホイルの折り返しの位置と幅。M2の折り込みを基に、カメラ側の面に沿わせた。

## V1 包みの接地

- V1の包みを **2.15 mm** 下げ、底面を約43.0 × 25.9 mmの範囲でならした。底面とガラス皿の天面は約0.02 mm重なり、回転中も接している。
- ガラス材質の影を接地面の中央へ寄せ、直下の色と反射を暗くした。外側のぼかしを薄くして、正面から底面と影が連続して見えるよう調整した。影の強さとぼかし幅は画面上の見え方に合わせた。
- 96フレームで360°回転し、先頭と末尾の姿勢が一致する。赤熱はフレーム58を起点に上がり、フレーム96で最大。1080×1920、24 fps、4.000秒のH.264を全フレームデコードして確認した。

# D01 フェーズB 制作レポート

Blender 4.3.2のヘッドレスEeveeで、1080×1920・16サンプルの本番ショットを描画した。動画は24 fpsのH.264。制作仕様とフェーズAの報告書、参照索引を確認し、形状と質感は既存モデルと索引の記述を基に調整した。[制作仕様](../../dame/D01_CODEX_SPEC.md) · [参照索引](../../dame/references/REFERENCE_INDEX.md) · [フェーズA報告書](REPORT_D01.md)

## モデルと画の修正

- **包みとガラス皿**　ホイルの下端に短い接触面を作り、包みの底面を皿に合わせた。床上40 mmの面に対し、皿の天面は高さ50.8 mm、中央のガラスは厚さ3.3 mm。皿の下面を3つのローラーに載せ、カプラー本体を下に収めた。V1では皿の材質に柔らかい接地影を加え、包みと一緒に回した。
- **M2の赤熱**　発光強度の係数を8.5から27に上げ、両端の縁、折り返しの縁、上側の稜線に分布を絞った。赤橙の発光の間に銀色の反射が残るようにした。V1はフレーム58から発光強度が上がり、96で最大。1と96の回転姿勢は一致する。反復再生で発光は初期状態へ戻る。
- **V2の断面**　右側（+X）から側面に正対する正投影。側板を開いた面にマグネトロン、曲がりのある導波管、庫内に通じる導波口を配置し、皿上のM2と同じ画面に収めた。
- **画角**　V1は扉を105°開き、庫内の開口が画面中央で高さの約90%を占める。V2は筐体外形の高さが画面の78.8%で、前側を横方向にトリミングした。V3は冒頭にM3を画面高の78.1%で収め、カメラと焦点を最も高い尖った先端へ移動。V4は共通のカメラ、照明、背景を使い、平滑面の連続した反射と折れ面ごとの反射を比較できる位置に置いた。画面高の占有率はM4が76.6%、M3が85.9%。

## 推測・誇張

- V2のマグネトロンと曲がった導波管の配置、断面の切り方、導波口の見える幅は、側面から経路を一望するための代表形状。庫内奥行き方向の経路として配置している。
- M2の局所的な接地影と赤熱の場所・強さは映像上の表現。回転は4秒で1周とし、3ローラーの配置も先頭と末尾で一致させた。
- V3はフェーズAで立ち上げた約9 cmの尖った折り目を使用。V4では比較画の占有率を合わせるため、M4のインスタンスだけ1.264倍とし、手前へ約84 mm移した。ライブラリのモデル寸法は元の設定を使用。

## 本番出力と実測時間

描画時間は Blender のレンダー呼び出しからPNG保存完了まで。秒/フレームは描画合計を納品フレーム数で割った値。V1は固定カメラの庫内を1080×1920で1枚描画し、動く範囲を各フレームで同じ画素密度とサンプル数で描画した。合成で範囲の境目をなじませ、上下を含む全画面のMP4に書き出した。試写、モデル作成、検品の時間は表の集計外。

## 再描画

シーンと素材は納品した [d01_models.blend](assets/d01_models.blend) に収録。Blender 4.3.2 と FFmpeg を使い、リポジトリのルートから実行する。各ショットの一時画像は `--work-dir` へ保存する。

```sh
d01_work_dir=$(mktemp -d)
for shot in V1 V2 V3 V4_flat V4_crumpled; do
  blender -b production/dame/assets/d01_models.blend -t 2 --python-exit-code 1 \
    -P production/dame/render_d01_phase_b.py -- "$shot" --work-dir "$d01_work_dir"
done
```

モデルとシーンの生成元は [build_d01.py](build_d01.py)。

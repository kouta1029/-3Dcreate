# D01 フェーズA 制作レポート

「ダメにはワケがある」D01のモデル一式、代表静止画4点、2秒のターンテーブルテストを制作した。フェーズBの作業はショット別の見積もりまで。

## 環境確認・計測

プリインストールの Blender 4.3.2 を使用。ヘッドレス Eevee で既定キューブを192×192、16サンプルで描画し、28.11秒でPNGを出力した。起動時に `EGL_BAD_MATCH` が出たが、その後の代表静止画4点とテスト連番48枚の書き出しまで確認した。

納品用の描画に先立ち540×960、16サンプルで4構図を試写した。照明を調整した試写は13.12秒、7.55秒、6.52秒、13.52秒（通常庫内、赤熱庫内、断面、マクロの順）。静止画は各試写の4倍、テスト連番は13.12秒＋47フレーム×7.55秒と見積もってから描画した。最長の見積もりはテスト連番の約6分8秒だった。

描画時間は Blender のレンダー呼び出しからPNG保存完了まで。連番の秒/フレームは全48フレームでの平均。テストのMP4は H.264、24 fps、2.000秒。1フレーム目から49フレーム目で皿と包みが1回転し、収録範囲をフレーム1–48にして初期姿勢の重複を避けた。

PNG4点の寸法とMP4の全フレームのデコードを確認した。包みの両端はホイルを折り込み、回転中に中身が見えないようにした。

## 推測箇所

- **M1**　通気孔の径とピッチ、エナメルの成形リブ、皿の縁、脚、ヒンジとグリップの断面、操作部の細部。導波口カバーからマグネトロンへ至る外側の矩形ダクト、フィンと電源モジュールの配置は断面説明用の代表形状。
- **M2**　サツマイモの曲がりと根跡の位置、ホイルの折り返しとねじりの配置、赤熱する縁と稜線の範囲。赤熱は映像上の発光マスクで表現した。
- **M3・M4**　個々の折り目と先端の輪郭、丸みのある食品の種類を特定しない外形、密着ホイルの折り返し位置。
- **M5**　カウンターと壁の寸法、継ぎ目と表面の質感。側面画の背景を覆うよう、幅を広めに取った。

## 誇張箇所

- **M2・M3のホイル**　薄い縁を描画で保つため、厚みを M2 は約0.13 mm、M3 は約0.17 mmに設定。M2は光が折り目で割れるよう、包みの表面の起伏も強調した。
- **M3の先端**　1枚のシートの折り返しを約0.09 mまで立ち上げ、先端のシルエットと根元の折り目をマクロ画で読めるようにした。
- **テストの回転**　2秒内で全周を確認できる30 rpmとした。ローラー3個の配置も継ぎ目で一致するよう、リングは1周の間に120°回転する。両方ともレビュー用の速度設定。
- **赤熱**　同じ露出の通常版と区別できる強さまで、縁と一部の稜線の発光を上げた。ガラス皿上には包みの接地が読めるよう、薄い補助陰影を重ねた。

## Blenderで確認する

[モデル一式](assets/d01_models.blend) の `05_model_library` シーンで M1〜M5 を編集できる。M1のドアは `Door hinge | adjust Open Degrees` のカスタムプロパティ `Open Degrees` で開く。断面は `03_cutaway_side` を選択するか、M1内の `Side panels | intact` と `Cut edges | cutaway` をビューレイヤーで切り替える。M2は `M2 | unheated wrap` と `M2 | red-hot wrap` を切り替えられる。庫内のカメラと照明は2つのヒーローシーンで共有している。

リポジトリのルートから再生成する場合は、Blender 4.3.2 と FFmpeg を使用する。

```sh
work_dir=$(mktemp -d)
blender -b -t 3 --python-exit-code 1 -P production/dame/build_d01.py
blender -b production/dame/assets/d01_models.blend -t 3 --python-exit-code 1 \
  -P production/dame/render_d01.py -- stills --work-dir "$work_dir"
blender -b production/dame/assets/d01_models.blend -t 3 --python-exit-code 1 \
  -P production/dame/render_d01.py -- loop --work-dir "$work_dir"
ffmpeg -y -framerate 24 -start_number 1 -i "$work_dir/frame_%04d.png" -frames:v 48 \
  -c:v libx264 -preset medium -crf 16 -pix_fmt yuv420p -movflags +faststart -threads 2 \
  production/dame/renders/d01/test_loop.mp4
```
